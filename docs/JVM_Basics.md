# JVM Basics

## What is JDK?
JDK (Java Development Kit) is used to develop Java applications. It includes JRE and development tools.

## What is JRE?
JRE (Java Runtime Environment) is used to run Java programs.

## What is JVM?
JVM (Java Virtual Machine) executes Java bytecode.

## What is Bytecode?
Bytecode is intermediate code generated after compilation.

## Write Once Run Anywhere
Java programs can run on any system with a JVM.

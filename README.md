# LearnTrack - Student & Course Management System

## 📌 Project Description
LearnTrack is a console-based application built using Core Java.
It allows admins to manage students, courses, and enrollments.

## 🚀 Features
- Add and view students
- Add and view courses
- Enroll students in courses
- View enrollments
- Deactivate students and courses
- Exception handling for invalid operations

## 🛠 Tech Used
- Java 21
- IntelliJ IDEA
- ArrayList (in-memory storage)

## ▶️ How to Run
1. Open project in IntelliJ
2. Run `Main.java`
3. Follow menu instructions

## 🧠 Concepts Used
- OOP (Encapsulation, Inheritance, Polymorphism)
- Collections (ArrayList)
- Exception Handling
- Layered Architecture (Entity, Repository, Service, UI)

## 📂 Project Structure
- entity/
- repository/
- service/
- util/
- exception/
- enums/
- constants/

## 📊 Design Notes
- Used ArrayList for dynamic data storage
- Used static IdGenerator for unique IDs
- Used inheritance (Person → Student)
- Separation of concerns across layers
